# 许可证政策

## 许可目标

项目开放协议、技术制品和公共知识，使不同村级节点、开发者和服务商能够实现兼容系统；开放许可不延伸到真实个人信息、交易数据和受限制的业务材料。

## 分层许可

| 内容 | 许可证 | 目的 |
|---|---|---|
| JSON Schema、样例、验证脚本、构建脚本和工作流 | Apache License 2.0 | 允许实现、修改、分发和商业应用，并提供明确的专利条款 |
| 白皮书、架构、治理、试点和协议说明文档 | CC BY 4.0 | 允许传播、改编和商业使用，同时要求署名和标注修改 |
| 外部引用与链接材料 | 原权利人的许可条件 | 本仓库不对第三方作品重新授权 |
| 个人信息、交易数据和受限业务材料 | 不适用开放许可证 | 继续受个人授权、合同和法律保护 |

具体文件范围以仓库根目录[LICENSE](../LICENSE)为准。

## 著作权与署名

著作权标识为：`Copyright 2026 AI原生开放助农网络贡献者`。

文档再利用应注明项目名称、原始仓库链接、CC BY 4.0链接，并说明是否修改。Apache-2.0内容的再分发应保留许可证和适用的版权、归属声明。

## 外部贡献

向本仓库主动提交的贡献，除提交者明确标注“Not a Contribution”外，按该文件所在范围对应的许可证提供。项目未来可以根据治理需要增加DCO；在此之前，不要求贡献者转让著作权。

## 数据与商标边界

开放代码不等于开放数据。真实农户、消费者和村级节点的信息不得因进入系统而自动公开。项目名称与标识的商标使用也不由Apache-2.0或CC BY 4.0自动授予。
