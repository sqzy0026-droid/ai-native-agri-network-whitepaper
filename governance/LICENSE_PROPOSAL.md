# 许可证建议与待确认事项

## 当前状态

本仓库尚未获得权利人对正式开放许可证的明确确认，因此当前不附带`LICENSE`文件，也不宣称已经开源。

公开可读不等于授予复制、修改和再分发权利。

## 建议的分层方案

| 内容 | 建议许可证 | 目的 |
|---|---|---|
| 协议、JSON Schema、SDK和一致性测试 | Apache License 2.0 | 允许不同主体实现兼容服务，并提供专利条款 |
| 公共参考服务器、索引和排序代理 | AGPL-3.0 | 防止修改后以网络服务方式完全封闭 |
| 白皮书、治理文件和培训材料 | CC BY-SA 4.0 | 允许传播和改编，同时保留署名与共享要求 |
| 样例数据 | CC0或CC BY 4.0 | 降低测试与教学使用门槛 |
| 个人和交易数据 | 不适用开源许可证 | 继续受授权、合同和法律保护 |

## 发布前必须由权利人确认

1. 是否接受分层许可；
2. 著作权主体名称；
3. 是否允许外部贡献；
4. 是否要求贡献者签署DCO或CLA；
5. 商标和“兼容实现”标识由谁持有；
6. 现有V3文档是否纳入同一许可。

在上述问题明确前，可以公开征求意见，但不应接受需要明确知识产权归属的代码合并。
