# 90天试点计划

## 1. 试点目标

验证一笔交易能否在没有中心平台人工导流的情况下完成，同时验证农户收益、节点工作量、权力约束和退出能力。

试点不是宣传活动，不以注册人数、页面访问量和发布商品数作为主要成功指标。

## 2. 范围

- 3个村级节点；
- 30户以内农户；
- 1至2类耐运输产品；
- 100名以内种子消费者；
- 1个食堂或工会采购场景；
- 1家物流服务商；
- 1个持牌支付渠道；
- 2个消费者AI排序策略；
- 不超过100笔真实订单。

## 3. 阶段与完成条件

### 阶段A：第1至30天，无AI闭环

交付：

- 村级节点和农户建档；
- 批次、证据、要约和订单事件；
- 普通表单完成询价、确认、物流和售后；
- 第一版责任矩阵。

完成条件：至少完成5笔内部或受控订单，能够处理取消和一项售后场景。

### 阶段B：第31至60天，加入Agri Harness

交付：

- 村级AI助手；
- 消费者意图解析；
- 多索引查询；
- 推荐凭证；
- 工具权限和人工审批；
- Agent会话恢复。

完成条件：AI不能绕过价格、支付和退款规则；模型中断后可以恢复任务。

### 阶段C：第61至90天，真实交易与破坏性验证

交付：

- 真实消费者交易；
- 至少一笔真实或受控争议；
- 两种推荐策略对照；
- 节点迁移与恢复；
- 模型、索引和物流适配器替换；
- 透明试点报告。

完成条件：四类验收全部获得证据，不以“基本成功”代替失败记录。

## 4. 四类验收

### 交易

- 批次到订单可追溯；
- 支付前人工确认；
- 物流事件完整；
- 售后责任可识别。

### 经济

记录每种销售方式下的：

```text
净收益 = 销售收入 - 生产成本 - 包装 - 物流 - 损耗 - 退款 - 数字服务 - 额外劳动时间
```

### 权力

- 村级操作员不能无痕删除历史；
- 推荐结果能够复算；
- 付费关系必须披露；
- AI越权调用被拦截；
- 农户有申诉与更正路径。

### 退出

- 更换模型；
- 关闭默认索引；
- 更换村级操作员；
- 导出并恢复节点；
- 更换物流适配器；
- 在没有原开发人员口头指导的环境复现。

## 5. 停止条件

- 农户净收益没有改善；
- 节点人员每笔订单投入时间不可承受；
- 消费者仅发生一次公益性购买；
- 物流损耗长期无法控制；
- 真实责任主体无法确定；
- 退出测试不能通过；
- AI错误长期需要人工重做；
- 默认索引形成事实上的唯一入口。

满足停止条件时，暂停扩张并公开原因。试点允许失败，不允许隐瞒失败。
